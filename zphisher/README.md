# Local Photo Demo

This is a simple local-only training app that captures a photo from the webcam and saves it to a local `uploads` folder on the machine.

## Run it

```bash
npm install
npm start
```

Then open:

```text
http://localhost:3000
```

## Notes

- The app is designed for safe, local educational use.
- Images are saved only on the machine running the app.
- It does not send data to a public server.
